## 0.1.0

- Initial release.
- OpenAPI 3.1 annotations for routes, parameters, bodies, responses, and schemas.
- Framework-agnostic document and JSON Schema models.
- Contact and license metadata on `OpenApiInfo`.
- Swagger UI HTML helper with a pinned default version and SRI hashes.
- `AxleDocs`, a framework-neutral payload for adapter routes.
- Swagger UI HTML with a pinned CDN fallback; local assets are generated by the
  CLI instead of a separate package.
