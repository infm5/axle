## 0.3.0

- Widened the `relic` constraint to `>=1.2.0 <3.0.0`; the test suite passes on
  Relic 1.2.0 and 2.0.0-rc.2.

## 0.2.0

- Aligned with `axle_core` 0.2.0.
- Added pass-through coverage for security schemes, operation security, and
  response headers.
- Updated the runnable example with API key enforcement, response headers,
  cookie parameters, content negotiation, constraints, `oneOf` schemas, and
  multipart uploads.
- Remains on Relic 2.0.0-rc.2.

## 0.1.0

- Initial release.
- `RelicApp.mountAxleDocs` for serving the OpenAPI document and Swagger UI.
- Standalone JSON and Swagger UI handlers.
- `AxleDocs`-based paths, title resolution, and cache headers.
- Optional local Swagger UI assets generated by `axle gen` and mounted from a
  directory.
- Swagger UI titles derived from the generated spec.
- Re-exports `axle_core` for one-import Relic apps.
- Targets Relic 2.0.0-rc.2.
- Swagger UI default is pinned to 5.34.0 with SRI hashes.
