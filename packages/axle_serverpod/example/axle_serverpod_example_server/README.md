# axle_serverpod_example_server

The Serverpod server for the [`axle_serverpod` example](../README.md).

- `lib/server.dart` registers the REST greeting route and mounts the axle docs.
- `lib/src/api/greeting_api.dart` contains the annotated handler and `Route`
  subclass backed by the generated `GreetingEndpoint.hello`.
- `lib/src/greetings/` contains the generated Serverpod greeting model and
  endpoint.
- `axle.yaml` controls generation.
- `openapi.json`, `openapi.yaml`, `lib/src/axle/openapi.g.dart`, and
  `assets/swagger-ui/` are generated by `axle gen`. The Dart constant lives
  outside `lib/src/generated/` because `serverpod generate` cleans that
  directory.

Run it from this directory:

```sh
dart run axle_cli:axle gen --check
dart run bin/main.dart
```
